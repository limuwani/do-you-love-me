# Do You Love Me? 💗 — Liquid Glass Edition

A playful, responsive romantic micro-site with animated **liquid-glass buttons** inspired by a short visual reference. The capsule itself stays put: the coloured, glossy fluid **swirls and sweeps inside the button**, with soft depth, reflections, and a satisfying squish. No framework or build step is required.

## Open it

Open `index.html` directly in a browser or deploy the repository as a static site (including GitHub Pages).

## Interactions

- **Yes, I do** — rose-tinted liquid activation followed by a heart-filled celebration and replay.
- **Maybe a little** — blue liquid activation with a friendly message.
- **No, not really** — on a desktop, the amber button flees across the entire screen when the mouse gets too close. On a phone or other touch device, tapping No splits it into two glass halves that fly apart and reunite somewhere else. It still responds when activated with the keyboard.
- **Light / dark** — switches the site and the glass treatment.

Animations include reduced-motion support. The result dialog supports Escape and a keyboard-focus loop. The visual is a CSS approximation, not a frame-identical 3D/WebGL rendering of the reference.

## Files

- `index.html` — semantic content and UI
- `style.css` — layout, responsive design, glossy pill / liquid animations
- `script.js` — button interaction, theme toggle, animated celebration, accessibility
